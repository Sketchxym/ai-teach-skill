# v0.3.0-alpha

本版本新增“给小白的 AI 基础课”，并保持原有 Transformer 结构测试课程不变。

## 新课程

- 四份 UTF-8 口述材料完整纳入课程来源；
- 按教学逻辑重组为 4 个模块、13 个知识节点；
- 覆盖大语言模型、Token、训练与推理、上下文、提示词、RAG、工具、MCP、Agent、Harness 和 Skills；
- 每个节点都有真实低压力练习和独立应用题；
- 建立前置依赖，并加入 3 张简洁中文教学图；
- 控制台可以列出两门课程，并要求学习者明确选择。

## 内容边界

源材料包含口述转写错误、产品名称和时效性判断。课程已合并重复内容、修正明确术语并补充教学连接，但没有把具体产品排名写成长期事实。全部节点、单元和测验仍保留 `review_required: true`。

## Alpha 限制

两门内置课程仍为 `draft/test`，只适合验证课程发现、路由、进度、复习和教学流程，尚不适合作为正式学习材料发布。
