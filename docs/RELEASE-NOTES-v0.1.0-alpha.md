# v0.1.0-alpha

这是 AI Teach Skill 的首个公开 Alpha 测试预览。

## 本次提供

- 面向学习者的 `teach` Skill；
- Codex 安装包 `teach-codex.zip`；
- WorkBuddy 安装包 `teach-workbuddy.zip`；
- Transformer 草稿测试课程及 12 张配图。

## 重要测试声明

内置课程**仅用于结构/流程测试，尚不适合正式学习**。它仍是 `0.1.0-draft`：89 个节点由 Markdown 标题机械生成，前置依赖尚未进行语义整理，所有 `review_required` 标记均保留，练习和独立测验仍为占位模板。

请勿把本次发布描述为经过审核的 Transformer 课程。

## 已知限制

- 尚需合并过细节点并定义真实学习目标；
- 尚需补齐前置依赖、讲解、例题、反例、误区和测验判定标准；
- 尚需在真实 Codex 与 WorkBuddy 环境中完成安装和交互验收；
- Alpha 阶段节点 ID 可能变化，后续版本可能需要状态迁移。
