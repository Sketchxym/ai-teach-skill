# 真实宿主人工验证清单

## Codex

1. 在隔离环境中安装 `teach-codex.zip`。
2. 确认自然语言请求能发现 `teach` Skill。
3. 确认能发现内置 Transformer 测试课程，并明确显示其草稿/待审核状态。
4. 检查提问打断后回到主线、编号选项降级、状态更新，以及跳过测验但不提升掌握等级。
5. 检查课程中的 12 张图片能否按相对路径显示。
6. 确认学习状态写在 Skill 安装目录之外。

## WorkBuddy

1. 导入 `teach-workbuddy.zip`，确认双语 frontmatter 被接受。
2. 确认普通相对 references 路径可读取。
3. 重复课程发现、图片、状态和教学流程检查。

还需记录宿主版本、安装目录、权限提示、包大小限制，以及是否提供可点击提问组件。
