# v0.2.0-alpha

本版本在同一个 `teach` Skill 中加入学习控制台，不改变 npx Skill 分发方式，也不新增 setup Skill。

## 新体验

- `$teach`：首次欢迎页或回访主页；
- `$teach 开始`、`$teach 继续`：进入自适应教学；
- `$teach 进度`：五档掌握证据、上次节点、待复习、薄弱项和推荐下一步；
- `$teach 课程`：查看课程版本、draft/test 状态和历史记录；
- `$teach 知识点`：按可追溯的原稿一级结构分组，再按需展开节点；
- `$teach 复习`：优先到期复习，其次有失败或重复尝试证据的节点；
- `$teach 帮助`：入口与自然语言示例。

自然语言“查看学习进度”“这门课有哪些知识点”“继续上次课程”“复习薄弱部分”与对应入口等价。

## 数据边界

控制台统计由本地确定性脚本计算，不生成虚构的百分比、学习时长或掌握结论。现有学习状态 Schema 保持兼容，不要求用户重置进度。

## 仍然适用的 Alpha 限制

内置 Transformer 课程仍然**仅用于结构/流程测试，尚不适合正式学习**。它保持 `0.1.0-draft`：89 个节点由 Markdown 标题机械生成，真实前置依赖尚未整理，全部 `review_required` 标记和占位测验保持不变。
