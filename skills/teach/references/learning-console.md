# 学习控制台

## 意图路由

`$teach` 是推荐的可复制表达，不是宿主专属 slash command。自然语言必须等价处理。收到学习控制请求时，从 Skill 目录运行：

```text
python scripts/learning_console.py "用户表达" --format json
```

稳定动作包括：

- 空动作或 `$teach`：学习主页；
- `开始`、`继续`：进入教学；
- `进度`：掌握证据、待复习、薄弱项和下一步；
- `课程`：已安装课程；
- `知识点`：分组知识地图；
- `复习`：到期复习优先，其次薄弱证据；
- `帮助`：入口和自然语言示例；
- 未知动作：简短回退，不猜测用户意图。

多课程且用户未明确选择时，必须先显示课程列表。不要根据最近状态替用户选择。

## 页面规则

直接使用脚本给出的结构化数据，不自行计算百分比、时长或掌握状态。输出保持短小：当前结论、必要证据、2—4 个下一步选项。

- 首次主页：课程名、draft/test 警告、开始 5 分钟体验、知识地图、进度、帮助。“5 分钟”只是短体验文案，不承诺准确计时。
- 回访主页：上次位置、`verified`/`durable` 概览、到期/薄弱数量、推荐下一步。
- 进度：显示五种 mastery state 的计数；无记录时明确说无记录，不虚构百分比。
- 课程：版本、draft/test 状态、是否有记录。
- 知识点：默认只显示分组及节点数。只有用户选择分组后，才用 `--group group-N` 展开节点、前置关系和状态。
- 复习：到期节点优先；没有到期或薄弱证据时，说明暂无并建议继续学习。
- 帮助：同时给出 `$teach …` 和自然语言例子。

脚本按原稿一级标题和节点顺序分组；这是可追溯的展示分组，不等于课程已经完成语义模块设计。

## 进入教学

`开始`或`继续`只负责选择候选节点。随后阅读 [teaching-runtime.md](teaching-runtime.md)，结合用户目标完成讲解、练习和证据更新。推荐节点不是强制顺序；用户目标或前置条件发生变化时可以调整，但不得绕过真实前置要求。

完成控制台动作后提供短的下一步选项。不要在普通讲解回答后重复完整控制台菜单。
