# 35. 为什么训练可以并行？

<!-- node_id: 35; source_lines: 665-677; review_required: true -->

## 原稿摘录

训练时，正确目标句全部已知。通过“右移目标 + 因果 Mask”，可以在一次前向计算中同时预测所有位置：

```text
位置 1：根据 <BOS> 预测“我”
位置 2：根据 <BOS> 我 预测“喜欢”
位置 3：根据 <BOS> 我 喜欢 预测“苹果”
位置 4：根据……预测 <EOS>
```

这些位置虽然拥有不同可见范围，但可以装进同一张下三角 Mask 的矩阵运算中。这是训练并行性的关键之一。
