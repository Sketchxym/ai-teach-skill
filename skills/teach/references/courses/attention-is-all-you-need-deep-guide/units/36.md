# 36. 为什么推理仍然逐词？

<!-- node_id: 36; source_lines: 678-692; review_required: true -->

## 原稿摘录

推理时没有正确答案。模型必须先生成“我”，才能把“我”加入上下文并生成“喜欢”。因此自回归 Decoder 的时间维仍然是：

```text
生成 1 → 放回输入 → 生成 2 → 放回输入 → ……
```

所以“Transformer 完全没有顺序计算”是错误的。更准确的说法是：

- Encoder 内部和训练时各已知位置能高度并行；
- 自回归生成仍按 token 顺序进行。
