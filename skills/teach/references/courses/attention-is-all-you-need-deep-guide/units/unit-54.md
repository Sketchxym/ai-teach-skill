## 原稿摘录

```text
I / love / apples
  → Encoder：得到三份上下文化源句表示
  → Decoder 输入 <BOS>
  → 预测“我”并放回输入
  → 预测“喜欢”并放回输入
  → 预测“苹果”并放回输入
  → 预测 <EOS>，生成结束
```

> **装回整机 ⑧**：至此，读者已经从输入 token 走到输出 token。后面的训练配方、复杂度和实验结果，是解释这台机器如何被训练好、为何有效、又在哪里昂贵。
