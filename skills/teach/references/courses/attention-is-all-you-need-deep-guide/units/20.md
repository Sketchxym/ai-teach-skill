# 20. “多个头”不是把模型维度乘八倍

<!-- node_id: 20; source_lines: 429-444; review_required: true -->

## 原稿摘录

原始基础模型：

\[
d_{model}=512,\qquad h=8,\qquad d_k=d_v=64
\]

每个头处理 64 维，8 个头拼接后正好回到 512 维：

\[
8\times64=512
\]

因此多头的主要价值是不同投影空间，而不是简单把最终通道数扩大 8 倍。
