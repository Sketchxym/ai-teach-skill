# 44.2 为什么长序列贵？

<!-- node_id: 44-2; source_lines: 829-837; review_required: true -->

## 原稿摘录

注意力分数矩阵是 \(n\times n\)。长度翻倍时，矩阵元素数量约变成四倍。

需要区分两件事：

- 标准 Attention 的理论计算/存储结构具有二次项；
- FlashAttention 等方法能显著减少显存读写和中间存储，但没有简单地把所有精确全局注意力计算都变成线性复杂度。
