# MCP：统一连接方式，不是新的大模型

<!-- node_id: mcp-connections; source_lines: 799-834; review_required: true -->

## 学习目标

把 MCP 理解为连接 AI 应用与外部能力的协议，并与具体工具区分。

## 核心解释

MCP 是 Model Context Protocol，可理解为一套连接规范。它帮助 AI 应用以较统一的方式发现和使用外部工具或数据源。天气查询是具体工具；MCP 更像约定插头形状和通信方式。是否能使用某项能力，还取决于客户端支持、服务端实现、权限和配置。

## 例子

同一个资料查询服务按 MCP 暴露后，不同兼容客户端可以用相似方式连接，而不必各自发明完全不同的接入流程。

## 易错点

把 MCP 当成会自己思考或自动完成任务的模型，也不要把“采用统一协议”理解成无需配置即可到处运行。

## 可观察的掌握证据

能用“工具”和“插座标准”的类比说明 MCP，并给出类比的边界。
