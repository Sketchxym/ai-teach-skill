# Harness：给 Agent 加权限、状态和护栏

<!-- node_id: harness-and-safety; source_lines: 878-948; review_required: true -->

## 学习目标

理解 Harness 是运行与管控层，能说出权限、审批、沙箱、状态、审计和失败处理的作用。

## 核心解释

材料把 Harness 描述为包在 Agent 外的运行管控层。它负责限制文件和数据访问，高风险动作要求人工批准，把任务限制在沙箱中，保存任务状态和审计记录，并处理超时或失败。这个词在不同产品中的范围可能不同，本课采用材料中的工程化含义。

## 例子

Agent 想发送邮件时，Harness 可以允许生成草稿，但在真正发送前暂停并请求用户确认。

## 易错点

把护栏当成一句“请小心”的提示词。真正的权限边界应由平台在执行层强制，而不是只靠模型自觉。

## 可观察的掌握证据

针对删除文件、发送邮件和读取客户数据三个动作，能设计不同的权限与审批规则。
