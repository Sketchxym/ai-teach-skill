# Token 与逐步生成：文字如何进入模型

<!-- node_id: tokens-and-generation; source_lines: 255-255; review_required: true -->

## 学习目标

知道 Token 是模型处理的文本片段，并能解释模型为什么逐步生成且同题可能得到不同答案。

## 核心解释

模型不直接处理“字义”，而是先由 tokenizer（分词器）把文本切成 Token，再映射成数字。Token 不固定等于一个汉字或一个单词；不同模型的切分方式可能不同。生成时，模型根据当前所有 Token 计算下一个 Token 的概率，再把选中的结果接回输入，重复到结束。

## 例子

“人工智能”可能被切成一个或多个 Token。模型生成“我喜欢学习”时，并不是一次写完整句，而是一步步选择后续片段。

## 易错点

把 Token 当作固定字数换算。材料中的平均换算只能帮助估算，不能当成对所有模型和文本都准确的公式。

## 可观察的掌握证据

能说明 Token、分词器和逐步生成三者的关系，并解释同一问题答案可能不同的原因。
