# 大语言模型是什么，又不是什么

<!-- node_id: llm-capability-boundary; source_lines: 192-253; review_required: true -->

## 学习目标

理解大语言模型擅长生成与推理，但不会天然知道实时信息，也不会自己执行外部动作。

## 核心解释

大语言模型（LLM）可以理解为一个根据已有上下文预测后续内容的数学模型。它能总结、改写、解释、比较和提出计划，但它输出的首先是内容或结构化指令。实时天气、企业内部数据、发邮件和修改文件等能力，需要平台把外部资料或工具接给它。模型给出的内容具有概率性，也可能出现看似合理却不真实的回答。

## 例子

问“解释什么是合同风险”时，模型可以直接组织说明；问“今天上海几点下雨”时，需要天气工具提供实时数据。

## 易错点

把“会说怎么做”误认为“已经做了”，或把流畅表达当成事实保证。

## 可观察的掌握证据

面对三个任务，能判断哪些只需模型生成，哪些必须取实时数据或调用工具。
