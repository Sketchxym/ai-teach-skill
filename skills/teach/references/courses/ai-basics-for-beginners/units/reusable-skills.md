# Skills：把可靠做法沉淀成可复用能力

<!-- node_id: reusable-skills; source_lines: 949-1009; review_required: true -->

## 学习目标

理解 Skill 与一次性提示词的区别，能写出一个小型 Skill 所需的目标、步骤、规则和输出。

## 核心解释

Skill 是交给 Agent 的可复用任务说明和配套资源。它通常包含名称与适用场景、目标、步骤、判断规则、工具使用方式和输出格式。一次性提示词解决当前请求；Skill 更适合反复出现、流程相对稳定的任务。不同平台的目录和文件格式可能不同，因此材料中的具体安装方式需要按实际宿主核对。

## 例子

“出门清单”Skill 可以先查地点与天气，再按下雨、空气质量和用户偏好生成清单，并规定每件物品都要说明原因。

## 易错点

把很长的提示词都叫 Skill，或在 Skill 中塞入与任务无关的通用原则。可复用性来自清晰边界和稳定流程，不来自篇幅。

## 可观察的掌握证据

为一个重复任务写出四项骨架：何时使用、执行步骤、判断规则、输出格式。
