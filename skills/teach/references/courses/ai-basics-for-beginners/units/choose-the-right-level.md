# 按任务选层级：聊天、工具还是 Agent

<!-- node_id: choose-the-right-level; source_lines: 1230-1249; review_required: true -->

## 学习目标

不背产品排行榜，而是根据任务复杂度、工具需求、风险和使用门槛选择方案。

## 核心解释

材料比较了多种 Agent 产品，但产品能力、名称和可用条件会变化，因此本课提取稳定的选择维度：任务是问答还是多步骤执行；是否需要操作文件或业务系统；风险动作能否审批；是否愿意配置环境；是否需要私有部署、开放扩展或特定办公生态。先明确任务，再选择最轻量、权限合适的方案。

## 例子

改写一段文案用普通聊天模型即可；读取多份文件并生成报告可用带文件工具的助手；需要长期自动执行和外部系统写入时，才考虑有状态、审批和审计的 Agent。

## 易错点

只问“哪个最强”，或依据一次产品宣传做长期结论。具体产品比较需要按当前版本、地区、价格与权限重新核实。

## 可观察的掌握证据

面对问答、文件分析和自动发送三种任务，能分别选择合适层级并说明风险控制。
