## 需要人工重点复核

1. 口述转写存在 `SKIA`、`skil`、`handler`、`codeassist`、`workbody` 等疑似错词；课程正文只修正能够从上下文确定的通用术语，产品名称不作为权威结论。
2. Token 与汉字数量、上下文规模、数据集体积等数字依模型和材料而变，课程不把口述估算写成固定换算。
3. 材料把 LLM 简化为“文字接龙”有助入门，但不足以覆盖全部能力；课程保留类比并明确它是简化模型。
4. RAG 能降低无依据生成风险，不能保证答案正确；课程已补充检索和来源仍需核对的边界。
5. MCP、Agent、Harness、Skill 在不同产品中的实现范围可能不同；课程只讲稳定角色，不承诺兼容性。
6. 材料 D 的产品能力、地区可用性和推荐带有时效性，正式发布前必须按当时版本重新核对。
