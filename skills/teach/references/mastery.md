# 掌握度与证据

状态按学习证据逐步提升，但不能互相替代：

- `unseen`（未接触）：还没有发生有意义的学习。
- `exposed`（已接触）：已经听过讲解或看过演示。
- `practiced`（已练习）：在提示、反馈或开放示例的帮助下尝试过。
- `verified`（已验证）：面对新的题目，能够独立提取或正确应用。
- `durable`（已稳固）：经过时间间隔后再次验证成功，最好还经历过交错练习或迁移任务。

只有可观察到的学习表现才能改变证据状态。学习者可以跳过任何测验继续学习，但节点必须保留原来的证据等级。自我报告的信心可以帮助调整节奏，却不能作为验证依据。直接照抄题干中的答案只算练习，不算独立提取。对不确定或部分成功的表现，应写入备注，而不是抬高状态。

复习间隔只是教学建议，不代表对记忆效果的保证：可以在约一天后首次复习，随后间隔数天；如果提取依然成功，再逐步延长。前置知识稳定后，可把相关节点交错练习。
